# OYYO Prime S3 0.13 · Connected model

**Optional account-backed assistance**

This OYYO product label selects a configured connected-model route. It is not a downloadable local weight file or a claim of OYYO foundation-model training. Requests use the connected account rather than on-device inference. Connection, account access, provider availability and applicable account limits are required.

| Item | Requirement |
| --- | --- |
| Local weight download | None for this option |
| Model RAM / VRAM | No local weight-residency requirement; the OYYO app still needs working memory |
| Offline operation | Not available for this route |
| Selection | Advanced connected-assistance setting; optional |
| Agent support | Role-specific prompts and team passes through the configured route |
| Notes | NotzUp's local-only policy remains separate and requires local models |
| Account / license | Connected service terms apply; the OYYO label does not grant a model-weight license |

Use it for authorised connected assistance when enabled and suitable for the task. Do not treat its output as proof of browsing, image generation, code execution, tests or external actions. Those need the actual matching tools and receipts.

This registry does not publish a parameter count, local quantization, speed guarantee or benchmark score for this route. Model/service configuration can differ from local text candidates. Do not use local hardware fit estimates as connected-service performance claims.
