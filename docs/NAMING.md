# OYYO Model Naming

Consumer-facing model families use stable product names independent from low-level package details.

Examples:

- `OYYO Nano 1.0`
- `OYYO Mini 1.0`
- `OYYO Core 1.0`
- `OYYO Code 1.0`

Machine package identifiers may include version and quantization, for example `oyyo-mini-1.0-q4`.

A base-model vendor/model name, source revision, license, conversion toolchain and exact artifact checksum must remain in provenance even when the consumer-facing model name is OYYO.
