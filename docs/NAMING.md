# OYYO model naming

Product names identify the configuration a user selects. Use the OYYO display name in selection tables, examples and user guides. Stable package IDs distinguish version and quantization, for example `oyyo-code-1.0-q4`.

A family label is not an architecture, measured skill level or proof of original OYYO training. Generation numbers are product identifiers, not benchmark rankings. Catalog cards distinguish local text candidates, speech packs, connected routes and roadmap families.

Retain exact artifact identity, revision, rights, required attribution, conversion lineage and applicable notices in the relevant provenance and distribution records. Consumer-facing OYYO naming does not remove those obligations or change ownership of third-party weights. Do not remove required notices to obscure an artifact's source.

For NotzUp, S1–S4 denotes a device performance profile for the same Tiny ALL speech pack. For Prime, “Connected model” denotes account-backed execution rather than local downloadable weights.
