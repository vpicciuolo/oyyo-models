# What models and runtime tools each do

| Goal | Model contribution | Additional requirement / boundary |
| --- | --- | --- |
| Marketing copy and campaigns | Plans, copy variations, budgets and briefs | Product facts, audience and user review; posting needs a real channel connector |
| Finance | Formula explanations, budget structure and scenario drafts | Reconciled calculations, source figures and appropriate review; no autonomous transactions |
| HR and recruiting | Job drafts, interview guides and onboarding materials | Human review of consequential employment decisions and appropriate handling of personal data |
| Engineering and coding | Analysis, proposed code and test plans | Actual file access, execution and meaningful tests through authorised tools |
| Research and company knowledge | Source-grounded synthesis | Relevant indexed documents or an actual search tool; citations must support the claim |
| Meetings and notes | Speech transcription, then local text-based summaries, decisions, actions and translation | NotzUp speech pack plus a qualified local text model; Windows beta short-clip limits apply |
| Images | Creative brief, style directions, composition and generation prompt | A separate image-generation tool; no qualified local image generator is in this text catalog |
| Short videos | Script, storyboard, shot list and production prompt | Video-generation/rendering tools, assets and their own compute/rights requirements |
| Image/document understanding | Text analysis after extraction where supported | A dedicated vision/OCR tool for pixels and scanned pages; a text model cannot see an image by its filename |
| PDF, Word and presentations | Content, structure and speaker notes | Export tools and visual review; exported files are not separate model releases |
| Spoken conversation | Reply text | Microphone permission, transcription and an available voice engine; a specific female voice is not guaranteed on every OS |
| Recurring work and social activity | Draft tasks and recommended next actions | A real scheduler, connector, account authorisation and execution receipts; suggested actions are not completed actions |

## Company coverage

Departments are served by role instructions, profiles, templates and tools rather than a new weight file for each job. The current role directory covers broad business work, but no finite catalog proves complete expertise in every company function or profession. Start with the desired outcome and appropriate source facts, then select specialists if needed.

## Creative style choices

A text model can translate “a cyberpunk marketing image” into a structured brief: subject, audience, product details, composition, colours, lighting, aspect ratio, copy placement and avoid-list. A style preset is not an image-generation model. Preview generation requires an actual available generator; do not present an unexecuted prompt as a generated image.

## Planned family names

Historical names such as OYYO Mini, Max, Vision and Growth describe product-family directions. Standalone downloadable weights for those exact names are not established by this runtime snapshot. The [full lineup](../README.md#local-text-lineup) lists the actual text candidates; Focus Mini is a specific catalog option, not proof of a separate general Mini release.
